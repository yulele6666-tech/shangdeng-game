# 美术素材说明

PNG 使用本地相对路径加载，具有透明背景。3 张时间氛围背景、玩家、3 张鸡帧、2 张紫蓝狗帧、花灯、红色大鼓全部随包提供。
火烛与木头为 game.js 内的 Canvas 图形；成功/失败弹窗由 index.html、ui.css 与花灯图组合，不需要额外结算图片。
全部图像由 OpenAI 内置 imagegen 工具为本项目制作或编辑。随项目按 MIT 协议提供，详见根目录 LICENSE。
