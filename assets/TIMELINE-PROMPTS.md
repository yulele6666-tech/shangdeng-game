# Timeline assets

Generated using the built-in image generation tool, preserving alpha PNG output.
Style reference: the existing temple-night.png; original character art and UI are retained.
No user reference images were attached, so the written scene descriptions were used.

Shared prompt: crisp square pixel clusters, thick charcoal outlines, flat solid color
regions, no gradients/complex lighting/blur. Orthographic 3/4 top-down RPG composition,
transparent sky, opaque terrain, open central route, fixed upper doorway anchor.

- background/village-dusk.png: warm dusk Hakka village street, peach/ochre/terracotta,
  lantern inviting stalls and a few villagers, simple scene, no blue night cast.
- background/ritual-night.png: blue-teal night, open hall foyer and wooden pillars,
  villagers hanging lanterns from stools and preparing ritual decorations at side tables.
- background/offering-midnight.png: darkest navy courtyard, dense red lantern strings,
  offerings, tables, chairs, crowded villagers and messy festive decorations along both
  sides, leaving central corridor x350..610 for real gameplay hazards.
- obstacles/bomb.png: isolated black round cartoon bomb, thick stepped outline,
  short fuse and amber pixel spark, no gradients or shadow. Warning rings are drawn
  by code to match the actual collision radius.
