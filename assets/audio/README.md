# 原创配乐《灯火归祠》

为本游戏编写的原创五声音阶像素风循环配乐，40 秒、96 BPM、16 小节。音色由正弦谐波合成的拨弦、铃音、低音与轻节拍组成，没有引用现有歌曲、采样库或第三方录音，也不宣称是传统客家曲牌的复原。

文件 lantern-home.wav 为 22050 Hz、16 位单声道 PCM WAV，使用浏览器原生 audio 元素循环播放。资源为本地相对路径，在线和 file:// 离线模式均可使用，无外部音乐服务。

点击开始游戏后播放，初始音量25%；可开关音乐、调节0–100%音量。暂停、失败、成功结算、切回角色选择和离开页面时暂停音乐；继续游戏后恢复。浏览器不允许播放时可点击“点击播放音乐”重试。偏好存入 localStorage；禁止存储不影响游玩。

本配乐和生成脚本按项目根目录 MIT 协议发布。生成脚本位于 tools/compose-music.py，仅供开发者重新导出音频，运行游戏不需要 Python。
